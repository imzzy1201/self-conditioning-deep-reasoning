# 列竖式乘法 Image-to-Image 数据集设计文档

## 1. 概述

本数据集是一个 image-to-image 数据集，用于训练模型学习竖式乘法的完整计算过程（Chain-of-Thought, CoT）。

- **输入图像**：一道竖式乘法题（仅包含乘数 a、被乘数 b 和乘号）
- **输出图像**：完整的竖式计算过程，包含所有中间步骤、进位标注和最终答案

核心目标：通过逐步骤的视觉推理链，使模型能够从输入的竖式乘法题图像，生成包含完整计算过程的输出图像。

---

## 2. 核心设计要点

### 2.1 递进式求和策略

传统竖式乘法在最后一步需要将 b 的所有数位对应的偏积一次性相加，当 b 位数较多时，涉及多个大数求和，推理难度骤增。

**本数据集采用递进式求和**：始终只做两个大数的加法，逐步累加偏积。具体流程：

1. 计算偏积 $P_0 = a \times b(0)$，其中 $b(0)$ 为 b 的最低位
2. 计算偏积 $P_1 = a \times b(1)$，左移 1 位得 $P_1 \ll 1$
3. **第一次求和**：$S_1 = P_0 + (P_1 \ll 1)$
4. 对 $i = 2, 3, \ldots, |b|-1$ 循环：
   - 计算偏积 $P_i = a \times b(i)$，左移 $i$ 位得 $P_i \ll i$
   - **第 $i$ 次求和**：$S_i = S_{i-1} + (P_i \ll i)$
5. 最终结果 $S_{|b|-1} = a \times b$

> 每次加法仅涉及两个大数，模型只需学会"两个大数相加"这一单一模式即可完成任意位数乘法的 CoT。

### 2.2 网格化数位布局

所有数字的每一位占据一个正方形网格单元（cell），保证严格对齐。特点：

- 每个数位独立占据一个 cell，等宽等高
- 按位值右对齐（个位在最右列）
- 使用等宽字体（monospace），确保每位数字视觉宽度一致

### 2.3 进位的视觉标注

进位（carry）是竖式计算 CoT 的关键信息，需要明确标注且不能与其他数字重叠。

**规则**：
- 进位数字的渲染尺寸为正常数字的 **1/2**
- 进位放置于产生该进位的数位的**左上角**
- 精确定位：以当前数位 cell 中心为基准，向左偏移 **半个 cell 宽度**，向上偏移 **1/4 个 cell 高度**，此点为进位数字的中心
- 由于进位尺寸仅为 1/2，其占据的区域为 (cell/2 × cell/2)，不会与任何相邻 cell 中的正常数字重叠

### 2.4 加法横线

每次两个大数相加时，在被加数与结果之间必须绘制一条水平横线，与传统竖式加法格式一致。

## 3. 计算流程详解

设 $a$ 为 $m$ 位数，$b$ 为 $n$ 位数，$b(0), b(1), \ldots, b(n-1)$ 为 $b$ 从低到高的各位数字，base 为进制（默认 10）。

### 3.1 步骤分解

| 步骤 | 行内容 | 说明 |
|------|--------|------|
| 0 | 显示 $a$ | 第一行：乘数 |
| 1 | 显示 $b$ 及乘号 $\times$ | 第二行：被乘数 |
| 2 | $P_0 = a \times b(0)$ | 第一个偏积，带乘法进位 |
| 3 | $P_1$ 左移 1 位 | 第二个偏积，带乘法进位 |
| 4 | 横线 + $S_1 = P_0 + (P_1 \ll 1)$ | 第一次求和结果，带加法进位 |
| 5 | $P_2$ 左移 2 位 | 第三个偏积，带乘法进位 |
| 6 | 横线 + $S_2 = S_1 + (P_2 \ll 2)$ | 第二次求和结果，带加法进法 |
| ... | ... | 依此类推 |
| $2n-2$ | 横线 + $S_{n-1}$ | 最终结果 |

### 3.2 乘法进位生成规则（计算 $a \times b(i)$）

从 $a$ 的最低位到最高位逐位计算：

```
carry = 0
for j = 0, 1, ..., m-1:
    product = a(j) * b(i) + carry
    digit_j = product % base
    carry    = product // base
if carry > 0:
    digit_m = carry  (最高位额外进位)
```

每个 `digit_j` 写入对应 cell，其对应的 `carry`（在计算 `digit_j` 时产生的进位）标注于 `digit_j` cell 的左上角。

### 3.3 加法进位生成规则（计算 $S_{i-1} + (P_i \ll i)$）

从最低位到最高位逐位相加：

```
carry = 0
for j = 0, 1, ..., max_len-1:
    sum = digit_j_of_S + digit_j_of_shifted_Pi + carry
    digit_j = sum % base
    carry    = sum // base
if carry > 0:
    digit_max_len = carry
```

每个结果数位 `digit_j` 写入对应 cell，其对应的 `carry` 标注于 `digit_j` cell 的左上角。

## 4. 网格与布局

### 4.1 网格定义

- **cell_size**：正方形网格单元的边长（像素），可配置
- 所有数字按位值列对齐：列 0 = 个位列，列 1 = 十位列，以此类推
- 行间距 = 1 个 cell_size（即行与行紧密排列，无额外间隔）

> 注：行间可能需要额外空间以容纳加法横线和进位标注，详见 4.3。

### 4.2 列数确定

所需最大列数 = $m + n$（乘积最多 $m+n$ 位）

但进位标注会向左偏移半个 cell，因此：
- 左侧需额外预留 **1 个 cell 宽度**（用于容纳最高位进位的左偏）
- 总列数 = $m + n + 1$（含左侧预留列）

### 4.3 行数确定

| 内容 | 行数 |
|------|------|
| 乘数 $a$ | 1 |
| 被乘数 $b$（含乘号） | 1 |
| 分隔线 | 1 |
| 偏积 $P_0$ | 1 |
| 偏积 $P_1$ 左移 | 1 |
| 横线 + 求和 $S_1$ | 2（横线 1 行 + 结果 1 行）|
| 偏积 $P_2$ 左移 | 1 |
| 横线 + 求和 $S_2$ | 2 |
| ... | ... |
| 偏积 $P_{n-1}$ 左移 | 1 |
| 横线 + 求和 $S_{n-1}$ | 2 |

**总行数** = $2 + 1 + 2 + 2(n-1) = 2n + 3$（当 $n \geq 2$）

当 $n = 1$ 时，总行数 = $2 + 1 + 1 = 4$（无加法步骤）

### 4.4 横线绘制

- 横线位于两个加数行与结果行之间
- 横线横跨从最低位到最高位的所有有效列
- 横线行高 = cell_size（与数字行等高，横线绘制在行的中间偏上位置，为进位留出空间）

### 4.5 乘号 $\times$ 的位置

乘号 $\times$ 放置于 $b$ 行的左侧，与 $b$ 的最高位对齐或位于其左侧一个 cell，可视效果而定。

### 4.6 偏积的位移表示

偏积 $P_i$ 左移 $i$ 位，在网格中表现为：$P_i$ 的个位对齐到第 $i$ 列（而非第 0 列）。其余高位依次向左排列。

## 5. 进位显示规则

### 5.1 位置计算

设某数位所在 cell 的中心坐标为 $(c_x, c_y)$，cell 大小为 $s$：

$$\text{carry\_center}_x = c_x - \frac{s}{2}$$
$$\text{carry\_center}_y = c_y - \frac{s}{4}$$

进位数字以 $\frac{s}{2} \times \frac{s}{2}$ 的尺寸渲染，中心对齐到 $(\text{carry\_center}_x, \text{carry\_center}_y)$。

### 5.2 非重叠证明

进位占据的矩形区域：

$$x \in \left[c_x - \frac{3s}{4},\; c_x - \frac{s}{4}\right]$$
$$y \in \left[c_y - \frac{s}{2},\; c_y\right]$$

- **与当前 cell 内数字不重叠**：当前数字占据 $[c_x - s/2, c_x + s/2] \times [c_y - s/2, c_y + s/2]$，进位的 x 范围 $[c_x - 3s/4, c_x - s/4]$ 与数字 x 范围 $[c_x - s/2, c_x + s/2]$ 有部分重叠，但进位在 y 方向仅占上半部分 $[c_y - s/2, c_y]$，且尺寸为 1/2，实际渲染区域不会与中心数字重叠（数字在 cell 正中，进位在左上角且小一半）。
- **与左侧 cell 数字不重叠**：左侧 cell 中心在 $(c_x - s, c_y)$，其数字占据 $[c_x - 3s/2, c_x - s/2] \times [c_y - s/2, c_y + s/2]$，进位 x 范围 $[c_x - 3s/4, c_x - s/4]$ 不在其中。
- **与上方进位不重叠**：上方 cell 的进位在 y 方向最低到 $c_y - s + s/4 + s/4 = c_y - s/2$，与当前进位最高点 $c_y - s/2$ 恰好相切，不重叠。

### 5.3 乘法进位 vs 加法进位

两类进位使用**相同的视觉规则**（位置、大小），区别仅在于上下文：
- 乘法进位：出现在偏积行中
- 加法进位：出现在求和结果行中

## 6. 图像规格

### 6.1 分辨率

- **image_size**：图像分辨率，可配置
- 宽度和高度**必须为 16 的倍数**（适配扩散模型的 patch 划分）
- 根据 cell_size、行数、列数自动计算，不足时 padding 到 16 的倍数

### 6.2 背景与颜色

- 背景：白色（#FFFFFF）
- 数字：黑色（#000000）
- 横线：黑色，线宽 = cell_size 的某个比例（如 2px 或 cell_size/16）
- 进位数字：黑色（与正常数字同色，靠尺寸区分）

### 6.3 字体

- 等宽字体（Monospace），如 Courier New、Consolas 等
- 正常数字字号 = cell_size 的适当比例（需保证数字在 cell 内居中且不溢出）
- 进位数字字号 = 正常字号的 1/2

### 6.4 对齐与边距

- 所有数字行右对齐（个位列对齐）
- 图像四周留有 padding，padding 大小可配置
- 最终图像尺寸向上取整到最近的 16 的倍数

## 7. 数据集生成参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `num_digits_a` | int | 乘数 a 的位数（$m$） |
| `num_digits_b` | int | 被乘数 b 的位数（$n$） |
| `base` | int | 进制，默认 10 |
| `cell_size` | int | 网格单元边长（像素） |
| `image_width` | int | 输出图像宽度（16 的倍数） |
| `image_height` | int | 输出图像高度（16 的倍数） |
| `font_name` | str | 等宽字体名称 |
| `padding` | int | 图像边距 |
| `line_width` | int | 横线宽度 |

### 7.1 数值生成

- $a$：均匀随机生成 $m$ 位数（最高位 $\neq 0$）
- $b$：均匀随机生成 $n$ 位数（最高位 $\neq 0$）
- 或者可根据需要控制特殊 case 的比例（如含 0 的数位、进位链等）

## 8. 完整示例

设 $a = 123$，$b = 456$（$m=3, n=3, \text{base}=10$）。

### 8.1 计算过程

```
b(0)=6, b(1)=5, b(2)=4

P_0 = 123 × 6 = 738
P_1 = 123 × 5 = 615,  P_1 << 1 = 6150
S_1 = 738 + 6150 = 6888

P_2 = 123 × 4 = 492,  P_2 << 2 = 49200
S_2 = 6888 + 49200 = 56088
```

### 8.2 竖式布局

```
            1   2   3
        ×   4   5   6
        ─────────────
        ¹   7   3   8        ← P_0 (¹为3×6=18的进位, ¹为2×6+1=13的进位)
    ¹   6   1   5            ← P_1 左移1位 (¹为2×5+1=11的进位, ¹为1×5+1=6无进位, 实际只有2×5=10+1=11进位1)
        ─────────────
        6   8   8   8        ← S_1 = 738 + 6150
    ¹   4   9   2            ← P_2 左移2位 (¹为2×4=8+1=9无进位; 实际1×4=4无进位)
        ─────────────
    5   6   0   8   8        ← S_2 = 6888 + 49200 = 56088
```

> 注：上图中进位用上标小字示意，实际图像中进位数字渲染为正常大小的 1/2，位于对应数位 cell 的左上角。

### 8.3 网格坐标示意

设 cell_size = s，左上角为原点，列从右往左编号（列 0 = 个位），行从上往下编号。

| 行 | 内容 | 占据列范围 |
|----|------|-----------|
| 0 | 123 | 列 2, 1, 0 |
| 1 | ×456 | 列 2, 1, 0（×在更左或同行左侧） |
| 2 | 分隔线 | 列 0 ~ 列 m+n-1 |
| 3 | P_0 = 738 | 列 2, 1, 0 |
| 4 | P_1 = 615 左移1位 | 列 3, 2, 1 |
| 5 | 横线 | 列 0 ~ 列 m+n-1 |
| 6 | S_1 = 6888 | 列 3, 2, 1, 0 |
| 7 | P_2 = 492 左移2位 | 列 4, 3, 2 |
| 8 | 横线 | 列 0 ~ 列 m+n-1 |
| 9 | S_2 = 56088 | 列 4, 3, 2, 1, 0 |

## 9. 设计决策总结

| 决策 | 理由 |
|------|------|
| 递进式求和（每次只加两个大数） | 避免 b 个大数同时相加，降低学习难度；模型只需掌握"两个大数加法"单一模式 |
| 网格化布局 | 保证数位严格对齐，便于模型从空间位置推断位值关系 |
| 进位左上角标注 + 1/2 尺寸 | 进位不与正常数字重叠，且视觉上自然表示"进到更高位" |
| 进位位置精确公式化 | 确保数据集生成一致性，模型可学习到稳定的视觉模式 |
| 等宽字体 | 每位数字宽度相同，与网格系统完美匹配 |
| 分辨率为 16 的倍数 | 兼容主流扩散模型的 patch 划分（通常 8×8 或 16×16） |
| 可配置 cell_size 和 image_size | 灵活适配不同模型和分辨率需求 |
